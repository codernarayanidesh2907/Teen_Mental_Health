# Teen_Mental_Health
# 🧠 Teen Mental Health Analysis using Machine Learning

## 📌 Project Overview

This project uses **Machine Learning to analyze factors associated with teen mental health** and identify patterns that may indicate potential mental health risks.

The project also includes an **interactive GUI** that allows users to enter relevant information and view the model's prediction.

> ⚠️ **Disclaimer:** This project is intended for educational and early-awareness purposes only. It is **not a medical or clinical diagnostic tool** and should not replace professional mental health advice.

## 🎯 Objectives

* Analyze factors associated with teen mental health.
* Preprocess and explore the dataset.
* Train and compare Machine Learning models.
* Evaluate model performance using appropriate metrics.
* Provide an easy-to-use GUI for interacting with the trained model.

## ⚙️ Machine Learning Workflow

1. Data collection and understanding
2. Data preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature preparation
5. Model training
6. Model evaluation
7. Model selection
8. Integration of the trained model with the GUI

## 🤖 Machine Learning

The project uses classification techniques to identify patterns in the dataset and generate predictions based on user-provided inputs.

**Evaluation Metrics:**

* Accuracy
* Precision
* Recall
* F1-Score

## 🖥️ GUI

An interactive GUI was developed using tkinter to make the model easier to use.

The interface allows users to:

* Enter relevant input parameters
* Submit the information to the trained model
* View the resulting prediction

## 📚 Key Learnings
